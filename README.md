# 한글 發音道場

韓文字母（한글）與常用單字的發音練習遊戲，介面為繁體中文。單一 HTML 檔案，無需安裝、不需後端。

**線上試玩：** https://USERNAME.github.io/hangul-dojo/

## 五種練習模式

| 模式 | 內容 |
| --- | --- |
| 認字母 | 看字母 → 選羅馬拼音（RR） |
| 找字母 | 看讀音與注音近似音 → 選字母 |
| 拼音節 | 子音＋母音（＋收尾子音 받침）→ 組出正確的字 |
| 學單字 | 韓文↔中文↔拼音三向隨機出題，答完附字母拆解 |
| 聽發音 | 聽韓語語音 → 選字母（需裝置支援韓語 TTS） |

## 收錄內容

- **字母 40 個**：基本子音 14、緊音（雙子音）5、基本母音 10、複合母音 11
- **單字 105 個**：無收尾音 57、有收尾音（받침）48，含音變標註（如 학교 → [학꾜]）
- 每個字母附《訓民正音》造字說明：子音象發音器官之形，母音取天（ㆍ）、地（ㅡ）、人（ㅣ）三才

## 特色

- **弱項加權**：答錯的字母／單字之後出現機率更高
- **熟練度追蹤**：字母表與單字表顯示各項答對比例，存在瀏覽器 localStorage
- **出題範圍可調**：依子音／母音分類或單字難度勾選
- **深色模式**：跟隨系統設定
- **鍵盤操作**：`1`–`4` 作答、`Enter` 下一題、`R` 重播發音、`Esc` 關閉字母表

## 部署

這是一個靜態頁面，把 `index.html` 放到任何靜態主機即可。

GitHub Pages：Settings → Pages → Source 選 `Deploy from a branch` → Branch `main` / `/ (root)` → Save。

## 說明

- 羅馬拼音採大韓民國文化觀光部 2000 年版（Revised Romanization）。
- 「聽發音」使用瀏覽器內建的 Web Speech API，需要裝置已安裝韓語語音；未偵測到時該模式會自動停用，其餘模式不受影響。
- 字體載入自 Google Fonts（Gowun Batang／Noto Serif TC／Noto Sans TC／IBM Plex Mono），離線時會自動退回系統字體。
